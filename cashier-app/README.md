# سيستم كاشير محل ملابس — نسخة السيرفر ☁️

نظام متكامل لمحل ملابس: **بيع + أوردرات شحن + مخزون بالمقاس/اللون + باركود + موردين + مصاريف + ديون + أرباح/خسائر + أصول + خزنة لعدة أشخاص**.

النسخة دي بتشتغل على **سيرفر + قاعدة بيانات** عشان كل الأجهزة تشترك في نفس البيانات.

---

## ⚙️ التشغيل محلياً (اختياري)

```bash
cd cashier-app
node server.js
```

وافتح المتصفح على `http://localhost:8080`

> **حسابات الدخول**: `admin / admin` (مدير) — `cashier / 1234` (كاشير)

---

## 🚀 الرفع على Railway (خطوة بخطوة)

### 1) ارفع المشروع على GitHub
1. اعمل حساب على [GitHub](https://github.com) لو معندكش.
2. اعمل **New Repository** واسمه مثلاً `clothing-pos`.
3. ارفع **كل ملفات المشروع دي** (من غير مجلد `data` و`node_modules`).
4. الطريقة الأسهل: من موقع GitHub اختار **uploading an existing file** واسحب كل الملفات، أو استخدم أمر git.

### 2) اربط Railway بـ GitHub
1. ادخل على [railway.app](https://railway.app) وسجل بحساب GitHub.
2. اضغط **New Project → Deploy from GitHub repo**.
3. اختار الريبو بتاعك `clothing-pos`.
4. Railway هيكتشف إنه Node.js ويرفعه تلقائياً (هتلاقي ملف `railway.json` و`package.json` جاهزين).

### 3) ⚠️ خطوة مهمة: قاعدة بيانات PostgreSQL
البيانات بتتحفظ في PostgreSQL (عبر Prisma) — مفيش داعي لأي Volume أو قرص دائم:
1. في المشروع على Railway اضغط **New → Database → Add PostgreSQL**.
2. Railway هيضيف متغير `DATABASE_URL` تلقائياً للسيرفس بتاعك.
3. بعد أول ديبلوي، شغّل مرة واحدة (من تبويب Railway → Shell أو محلياً بنفس `DATABASE_URL`):
   ```bash
   npm run db:push
   ```
   ده بيطبّق شكل الجداول (`prisma/schema.prisma`) على القاعدة.

> أول مرة السيرفر يشتغل على قاعدة فاضية، هيتزرع تلقائياً ببيانات تجريبية (منتجات + حساب مدير/كاشير).

### 4) افتح الموقع
1. Railway هيديك **Domain** (لينك) — اضغط **Settings → Networking → Generate Domain** لو مش ظاهر.
2. افتح اللينك وسجل دخول بـ `admin / admin`.

### 5) 🔒 أمان (مهم جداً)
1. بعد أول دخول، غير كلمة سر المدير فوراً من **الكاشير والصلاحيات**.
2. اعمل حساب منفصل لكل شخص بيستلم فلوس.

## 📁 هيكل المشروع

```
cashier-app/
├── server.js          ← السيرفر (API + قاعدة البيانات)
├── package.json       ← إعدادات التشغيل
├── railway.json       ← إعدادات Railway
├── .gitignore         ← ملفات مستبعدة من الرفع
├── prisma/
│   └── schema.prisma  ← شكل جداول قاعدة البيانات
└── public/
    └── index.html     ← الواجهة كاملة
```

---

## ❓ أسئلة شائعة

**البيانات بتتحفظ فين؟** في قاعدة بيانات PostgreSQL (متصلة عن طريق `DATABASE_URL` و Prisma) — مفيش ملفات محلية ولا Volume مطلوب.

**عايز نسخة احتياطية؟** من داخل النظام: **الإعدادات ← تصدير البيانات** — هينزل ملف JSON احتفظ بيه، وتقدر ترجّعه بـ **استيراد**.

**ممكن أستخدمه من الموبايل؟** أيوه، النظام متجاوب وبيشتغل من أي متصفح على الموبايل طالما متصل بنفس اللينك.
